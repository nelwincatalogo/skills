# AI Agent Skills

A collection of AI agent skills for enhancing development workflows.

## Available Skills

### [git-commit-message](./skills/git-commit-message/)
Generates concise, informative Git commit messages following the Conventional Commits specification with Gitmojis.

**Use when:** Creating git commit messages, writing commit messages based on code changes, or asking for commit message suggestions.

### [hookstate](./skills/hookstate/)
Guide for using Hookstate state management library in React applications.

**Use when:** Implementing state management with Hookstate, setting up global/local states, or working with nested state structures.

## Installation

Install individual skills using the skills CLI:

```bash
npx skills add nelwincatalogo/<skill-name> -g
```
